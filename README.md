# مصروف البيت: طريقة التشغيل

الإعداد ده بيتعمل **مرة واحدة بس** من كمبيوتر، وبياخد حوالي ١٥ دقيقة. كله مجاني.

---

## ١) تجهيز المزامنة على Firebase

1. ادخل على **console.firebase.google.com** بحساب Gmail.
2. **Create a project** ← اكتب اسم (مثلاً `masroof-elbeit`) ← اقفل Google Analytics ← Create.
3. من القائمة: **Build ← Firestore Database ← Create database**
   - Location: اختار أقرب حاجة (مثلاً `europe-west`).
   - اختار **Production mode** ← Create.
4. افتح تبويب **Rules**، امسح اللي فيه، والصق ده، وبعدين **Publish**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /households/{hid}/{col}/{docId} {
      allow read, write: if hid.size() >= 20;
    }
  }
}
```

5. اضغط الترس ⚙️ جنب Project Overview ← **Project settings** ← تحت **Your apps** اضغط أيقونة الويب `</>`
   - اكتب أي اسم ← **Register app** (ما تعلّمش على Hosting).
   - هيظهرلك كود فيه `const firebaseConfig = { apiKey: ...}`. **انسخه واحتفظ بيه**، هتحتاجه في الخطوة ٣.

---

## ٢) رفع التطبيق على الإنترنت (Netlify)

1. فك ضغط الملف `masroof-app.zip` على الكمبيوتر، هيطلعلك فولدر `app`.
2. ادخل على **app.netlify.com** واعمل حساب مجاني.
3. اختار **Add new site ← Deploy manually**، واسحب فولدر `app` كله وارميه في المربع.
4. بعد ثواني هيديك رابط زي `https://xxxx.netlify.app`. ممكن تغيّر الاسم من **Site configuration ← Change site name**.

> الرابط ده هو التطبيق. افتحه من الموبايلين.

---

## ٣) أول تشغيل

**على الموبايل الأول:**
1. افتح الرابط ← اكتب اسمك ← **أنا أول واحد**.
2. الصق كود Firebase من الخطوة ١ ← **تفعيل المزامنة**.
3. هيظهرلك **كود الانضمام** ← ابعته للموبايل التاني على واتساب.

**على الموبايل التاني:**
1. افتح نفس الرابط ← اكتب الاسم ← **معايا كود انضمام** ← الصق الكود.

> كود الانضمام هو مفتاح حساباتكم، ما تبعتهوش لحد غيركم.

---

## ٤) تثبيته كأبلكيشن على الشاشة الرئيسية

**أندرويد (Chrome):** افتح الرابط ← النقط التلاتة ⋮ ← **Add to Home screen / تثبيت التطبيق**.

**آيفون (Safari لازم، مش Chrome):** افتح الرابط ← زرار المشاركة ⬆️ ← **Add to Home Screen / إضافة إلى الشاشة الرئيسية**.

بعدها بيفتح لوحده زي أي أبلكيشن، ومن غير شريط المتصفح.

---

## إزاي بيشتغل من غير نت

- أول مرة لازم يكون فيه نت علشان يحمّل.
- بعد كده تقدر تسجّل في أي وقت. المصاريف بتتحفظ على الموبايل، وأول ما النت يرجع بتتزامن لوحدها.
- فوق في الشاشة هتلاقي حالة المزامنة: **متزامن ✓** أو **بدون نت · هيتزامن بعدين**.

## ملاحظات

- **التذكيرات** بتظهر في الصفحة الرئيسية لحد ما تسجّل المصروف بتاع الشهر، والمبلغ بتكتبه بنفسك كل مرة (بيقترح عليك آخر مبلغ).
- **التصدير لـ Excel** من صفحة التقارير بيطلع ملف CSV بيفتح في Excel على طول.
- **نسخة احتياطية** من الإعدادات: احفظ نسخة كل فترة على Google Drive أو واتساب.
- لو عدّلت حاجة في ملفات التطبيق، ارفع الفولدر تاني على Netlify من **Deploys** وهيتحدّث عند الاتنين.
